# sommuvie

[Instruções de uso e licença](USAGE.md) · [Downloads](https://github.com/sunshineAle/sommuvie/releases)

O **sommuvie** é um aplicativo independente para assistir a filmes e séries e ouvir músicas de uma biblioteca de mídia compatível com o **Jellyfin**.

O projeto busca uma experiência de TV limpa e fluida, com navegação por controle remoto, para **Samsung Tizen** e **Android TV**.

> **Status: em desenvolvimento.** A versão 0.6.2 e seu código-fonte correspondente estão disponíveis em [Versões e downloads](https://github.com/sunshineAle/sommuvie/releases). Pacotes posteriores em teste nos aparelhos serão publicados após a conferência.

O sommuvie é um projeto independente e **não é afiliado nem endossado pelo Jellyfin**.
