# sommuvie

O **sommuvie** é um aplicativo independente para assistir a filmes e séries e ouvir músicas de uma biblioteca de mídia compatível com o **Jellyfin**.

O projeto busca uma experiência de TV limpa e fluida, com navegação por controle remoto, para **Samsung Tizen** e **Android TV**.

> **Status: em desenvolvimento.** O repositório público está sendo preparado. O código-fonte, os pacotes de instalação, a documentação de compatibilidade e as versões para download ainda não foram publicados aqui. Não há uma versão pública do sommuvie disponível neste repositório.

O sommuvie é um projeto independente e **não é afiliado nem endossado pelo Jellyfin**.

As diretrizes de desenvolvimento, as condições de contribuição e os avisos legais serão publicados após revisão, sem expor dados de equipamentos, endereços, credenciais ou certificados particulares.
